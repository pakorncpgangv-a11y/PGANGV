2️⃣ Tab ยอดขาย - วิธีกรอกข้อมูลแบบละเอียด

สูตรคำนวณอัตโนมัติ (ไม่ต้องกรอกเอง):
รวมกะดึก รถ = รถกะ2(20-24) + รถกะ3(00-08)
รวมกะดึก ก๊าซ = ก๊าซกะ2 + ก๊าซกะ3
รวมกะดึก ยอดขาย = ยอดกะ2 + ยอดกะ3
ปิดวัน รถ = รถกะ1+กะ2+กะ3, ก๊าซ = ก๊าซกะ1+กะ2+กะ3, เงิน = ยอดกะ1+กะ2+กะ3
  1. เลือกวันที่: ช่องวันที่ * ต้องเลือกก่อน เช่น 2025-06-01 ถ้าวันนี้มีอยู่แล้ว ระบบจะทับของเดิม (upsert)
  2. กรอกกะเช้า 08.00-20.00: รถ, จำนวนก๊าซ (กก. ทศนิยม 3 ตำแหน่ง), ยอดขาย (บาท)
  3. กรอกกะ2 20.00-24.00: รถ, ก๊าซ, ยอดขาย
  4. กรอกกะ3 00.00-08.00: รถ, ก๊าซ, ยอดขาย
  5. ระบบคำนวณ รวมกะดึก และ ปิดวัน ให้ทันที
  6. ทิปเช้า/ทิปกดึก: ใส่จำนวนเงินทิป
  7. หมายเหตุ: ใส่สาเหตุ เช่น "ปิดหัวจ่าย 2 ซ่อมบำรุง", "ตรวจ payin"
  8. ดู KPI Preview ด้านล่างฟอร์ม จะบอกทันทีว่าผ่าน 16,000 ไหม
  9. กด บันทึก (ทับถ้าซ้ำ) - ถ้าวันที่ซ้ำจะทับของเดิมเลย
  10. ข้อมูลจะไปโผล่ในตารางด้านล่าง พร้อมสีตาม KPI และ Sync ไป Supabase อัตโนมัติ

แก้ไข/ลบ: ในตารางกด "แก้" จะดึงข้อมูลขึ้นมาที่ฟอร์มด้านบนให้แก้แล้วบันทึกทับ, กด "ลบ" จะลบทั้งในเครื่องและ Supabase

7️⃣ สีตาม KPI 16,000 กก.

≥16,000 เขียว + 🏆 ผ่าน KPI โดดเด่น เรืองแสง
15,000-15,999 เหลือง ใกล้เป้า
14,000-14,999 ส้ม ปานกลาง

กราฟ: เส้นประแดงที่ 16,000 คือเป้า, แท่งเขียวที่เกินเส้นคือวันที่ทำได้เกินเป้า มี tooltip "🏆 ผ่าน KPI โดดเด่น!"

8️⃣ Tips การใช้งาน

  • ก็อปไฟล์ไปเครื่องไหนก็ใช้ได้ ไฟล์เดียวจบ
  • วันที่ซ้ำระบบทับให้อัตโนมัติ หรือกดปุ่ม "ลบวันที่ซ้ำ"
  • กราฟถ้าไม่มีข้อมูลจะสร้างตัวอย่าง 30 วันให้ดู
  • Export CSV เอาไปทำรายงานต่อ
  • ไม่ล็อกหน้าจอ เลื่อนตามหน้าได้ปกติ
  • มือถือก็เปิดได้ responsive
  • ข้อมูลอยู่ทั้งในเครื่องและ Supabase ลบ cache ก็ดึงกลับมาได้

🔟 Tab กระทบยอดเงินสด — ขั้นตอนใช้งานรายวัน

  1. Orada บันทึกยอดขายประจำวันในแท็บ "ยอดขาย & KPI" ตามปกติ
  2. Leader เปิดแท็บ "กระทบยอดเงินสด" เลือกวันที่รายงาน — ช่อง ปตท. (ระบบ) ดึงจากยอดขายของ Orada ให้อัตโนมัติ (00-08 = กะ3, 08-20 = กะเช้า, 20-24 = กะ2) พิมพ์ทับได้
  3. กรอก นับจริง 3 ช่วงเวลา (หรือกด "ปัดนับจริงขึ้นเป็นบาทเต็ม") — ผลต่าง กะเช้า/กะกลางคืน/รวม คำนวณเอง
  4. เงินเข้าธนาคาร ใช้ยอด ปตท. รวมให้เอง และ ยอดยกมาในตู้ ดึงจากยอดนับจริงของวันก่อน (ติ๊กออกเพื่อกรอกเอง)

  6. ถ้ามีผลต่างผิดปกติ (เกิน ≥ 1 บาท หรือขาด) ต้องใส่หมายเหตุก่อนส่ง
  7. กด ส่งให้ผู้จัดการยืนยัน → Manager ตรวจ แล้วกด ยืนยันรายงาน (ใส่รหัสผ่านซ้ำ) หรือ ตีกลับ พร้อมเหตุผล
  8. หลังยืนยัน รายงานถูกล็อก — Manager กด พิมพ์ / PDF (A4) หรือ บันทึกเป็นรูป เพื่อแจ้งหน่วยงานอื่น
  9. ถ้า Leader แก้ไขรายงานที่ส่งแล้ว สถานะจะกลับเป็นร่างและต้องส่งใหม่

-- 3) ฟังก์ชัน login (ตรวจรหัสผ่านที่ฝั่งเซิร์ฟเวอร์)
create or replace function public.ngv_login(p_user text, p_pass text)
returns json language plpgsql security definer set search_path = public, extensions as $$
declare u public.ngv_users;
begin
  select * into u from public.ngv_users where username = lower(trim(p_user));
  if not found or u.pass_hash <> crypt(p_pass, u.pass_hash) then
    return json_build_object('ok', false);
  end if;
  return json_build_object('ok', true, 'username', u.username, 'name', u.display_name, 'role', u.role);
end $$;

-- 4) ฟังก์ชันยืนยัน / ยกเลิกการยืนยัน — เฉพาะ manager + ต้องใส่รหัสผ่านซ้ำ
create or replace function public.ngv_recon_action(p_date text, p_user text, p_pass text, p_action text)
returns json language plpgsql security definer set search_path = public, extensions as $$
declare u public.ngv_users; r public.ngv_recon;
begin
  select * into u from public.ngv_users where username = lower(trim(p_user));
  if not found or u.pass_hash <> crypt(p_pass, u.pass_hash) then
    return json_build_object('ok', false, 'msg', 'รหัสผ่านไม่ถูกต้อง');
  end if;
  if u.role <> 'manager' then
    return json_build_object('ok', false, 'msg', 'เฉพาะผู้จัดการเท่านั้น');
  end if;
  select * into r from public.ngv_recon where date = p_date for update;
  if not found then
    return json_build_object('ok', false, 'msg', 'ไม่พบรายงานวันที่ ' || p_date);
  end if;

  if p_action = 'confirm' then
    if r.status <> 'submitted' then
      return json_build_object('ok', false, 'msg', 'รายงานยังไม่ถูกส่ง หรือถูกยืนยันไปแล้ว');
    end if;
    update public.ngv_recon
       set status = 'confirmed', confirmed_by = u.display_name, confirmed_at = now(), reject_note = null
     where date = p_date;
  elsif p_action = 'reopen' then
    if r.status <> 'confirmed' then
      return json_build_object('ok', false, 'msg', 'รายงานนี้ยังไม่ได้ยืนยัน');
    end if;
    update public.ngv_recon
       set status = 'draft', confirmed_by = null, confirmed_at = null,
           submitted_by = null, submitted_at = null,
           reject_note = u.display_name || ': ยกเลิกการยืนยันเพื่อแก้ไข', updated_at = now()
     where date = p_date;
  else
    return json_build_object('ok', false, 'msg', 'คำสั่งไม่ถูกต้อง');
  end if;
  return json_build_object('ok', true);
end $$;

grant execute on function public.ngv_login(text, text) to anon;
grant execute on function public.ngv_recon_action(text, text, text, text) to anon;
